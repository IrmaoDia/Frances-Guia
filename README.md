# Guia Energético — versão francesa

Abra `index.html` no navegador. Não é necessário instalar dependências.

- `css/style.css`: aparência e comportamento responsivo.
- `js/main.js`: carrossel e FAQ.
- `imagens/`: mockups vetoriais locais e espaços para imagens reais.

Configure a URL do checkout no atributo `href` do botão com `id="begin_checkout"` em `index.html`.

Os depoimentos usam `depoimento/prova1.mp4`, `prova2.mp4` e `prova3.mp4`. O carrossel exibe um vídeo por vez, com rolagem lateral, roda do mouse, setas e indicadores. O vídeo visível reproduz sem som em loop; “Cliquez pour écouter” reinicia com áudio e controles. Vídeos fora de exibição ficam pausados.

As respostas do FAQ reutilizam trechos da copy fornecida, pois o documento contém somente as perguntas. A copy comercial foi preservada conforme o documento recebido; a implementação não verifica ou comprova suas alegações.
